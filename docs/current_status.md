## 최신 실험과 기본 지원 코드의 관계

최신 날짜의 시험과 기본 지원 코드가 같다고 가정하지 않는다. 이번 정비의
기능 대조 기준은 `main`의 `89c5fdb`, 저스로틀 yaw 개선 실험의
`a052dd9`(`feat/low-throttle-yaw-control`)다. 문서·주석 정비는 이 기본 코드의
제어 동작을 바꾸지 않는다. 실험 코드는 축 우선순위
배분·yaw 권한 상태·무장 확인을 추가하지만, 기본 코드의 이후 문서·CI·발표자료
분리 변경을 모두 포함하지 않는다. **실험 코드 전체를 최신 기본 코드로 교체할
상태라는 뜻이 아니다.** 실행할 커밋과 대응 지상국을 먼저 확인한다.

8월 19일 기록의 다섯 사이클은 위 실험 구성에 해당한다. 이를 기본 믹서의
성능이나 무조종 위치 유지 성공으로 옮겨 쓰지 않는다. 실제 기체에 마지막으로
업로드된 커밋은 소스 폴더나 로그 파일명만으로 확정할 수 없다.

## 현재 검증과 남은 관문

2026-09-07 기본 코드의 Python 테스트 및 호스트 네이티브/SIL 실행을 포함한
`unittest` **175개가 통과**했다. 이 개수는 바깥 테스트 개수이며 내부 C++
케이스를 다시 합산하지 않는다. 주력·보류 후보·진단 **9개 스케치도 ESP32
코어 3.3.7에서 컴파일 통과**했다. CI 고정 코어 3.3.10의 실행 결과와는
구분한다. 구체적인 빌드·검사 기록은
[이번 정합성 점검 기록](reports/2026-09-07-documentation-audit.md)에 남긴다.

기체 없는 검사와 과거 실비행 기록을 구분한다. 새로운 센서 수신 성공, 최신
보드 빌드의 비행 성능, 현재 배터리·기구 상태를 이번 문서 점검으로 확정하지 않는다.
작업 시작·종료 절차는 [작업 흐름](workflow.md)을 따른다.
