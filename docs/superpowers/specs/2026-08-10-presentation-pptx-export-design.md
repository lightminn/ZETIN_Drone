# AI 창업캠프 드론 발표자료 PPTX 내보내기 설계

## 목표

HTML 기준본 77장을 16:9 PPTX로 내보낸다. 화면 구성은 현재 Chrome 렌더링과
동일하게 유지하고, 10개 영상과 77개 발표자 노트를 PPTX 안에 포함한다.

결과 파일은 다음 경로에 둔다.

`docs/presentations/ai-startup-camp-drone/ZETIN_Drone_AI_Startup_Camp.pptx`

## 선택한 방식

각 슬라이드를 2560×1440 PNG로 캡처해 전체 배경으로 넣고, 영상 슬라이드에는
HTML에서 측정한 영상 위치와 크기로 실제 MP4 미디어를 덮는다.

- HTML을 PowerPoint 도형으로 다시 작성하는 방식은 77장 전체에서 글꼴·줄바꿈·
  사용자 정의 컴포넌트를 정확히 재현하기 어렵다.
- PDF를 PPTX로 변환하면 영상과 발표자 노트가 사라진다.
- 이미지 배경 방식은 개별 텍스트 편집성은 포기하지만 기준본과 시각적으로 가장
  일치하며, 최종 발표용 파일이라는 목적에 맞는다.

## 생성기

`docs/presentations/ai-startup-camp-drone/export_pptx.cjs`가 다음 순서로 동작한다.

1. 임시 디렉터리에 PptxGenJS 4.0.1과 chrome-remote-interface 0.34.0을 설치한다.
2. 로컬 HTTP 서버와 격리된 headless Chrome을 실행한다.
3. 썸네일 레일·발표 컨트롤·애니메이션을 숨긴 1280×720 화면을 2배 해상도로
   캡처한다.
4. 영상 슬라이드에서는 FFmpeg로 0.5초 프레임을 추출하고 Pillow로 영상 영역과
   재생 표식을 합성해, Chrome의 영상 코덱 지원 여부와 무관한 화면 캡처와 영상
   커버 이미지를 만든다.
5. 슬라이드 배경, 발표자 노트, 영상 위치를 PptxGenJS에 전달해 PPTX를 만든다.
6. 임시 서버·Chrome·프로필·스크린샷·npm 의존성을 항상 정리한다.

## 영상 호환성

- 기존 H.264 MP4 9개는 그대로 내장한다.
- HEVC인 `hover_demo.mp4`는 생성 중 H.264/AAC, yuv420p MP4로 변환해 내장한다.
- 영상은 PPTX 내부에 포함하며 외부 파일 경로에 의존하지 않는다.
- PowerPoint 데스크톱에서는 영상 커버를 클릭해 재생한다. PPTX의 자동재생은
  생성 라이브러리가 안정적으로 지원하지 않으므로 설정하지 않는다.
- LibreOffice·웹 미리보기·Google Slides에서의 미디어 재생은 보장하지 않는다.

## 검증 기준

- PPTX는 16:9, 77장이어야 한다.
- 10개 MP4가 패키지 내부에 있어야 하며 모두 H.264여야 한다.
- 발표자 노트 77개가 있어야 한다.
- ZIP 무결성 검사와 python-pptx 로드가 성공해야 한다.
- LibreOffice가 77쪽 PDF로 변환할 수 있어야 한다.
- 표지, 대표 본문, 영상 슬라이드, 마지막 장을 이미지로 확인해 잘림이나 UI 잔상이
  없어야 한다.
