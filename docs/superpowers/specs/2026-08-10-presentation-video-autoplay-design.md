# 발표자료 영상 자동재생 설계

## 목표

영상이 포함된 슬라이드가 활성화되는 즉시, 발표자의 추가 클릭 없이 해당 영상을
처음부터 자동재생한다.

## 선택한 방식

`deck-stage`의 슬라이드 활성화 경로에서 영상 수명주기를 함께 동기화한다.
HTML의 `autoplay` 속성만 추가하는 방식은 화면에 보이지 않는 영상까지 동시에
재생될 수 있고, 별도 페이지 스크립트는 이미 존재하는 `slidechange` 처리와 초기
슬라이드 처리를 중복하게 되므로 사용하지 않는다.

## 동작

- 활성 슬라이드 안의 모든 `video` 요소에 `play()`를 호출한다.
- 비활성 슬라이드 영상은 `pause()`하고 재생 위치를 0초로 되돌린다.
- 다시 영상 슬라이드에 들어오면 항상 처음부터 재생한다.
- 현재 자료의 영상은 모두 `muted`이므로 Chrome의 사용자 입력 없는 재생 정책을
  만족한다.
- `play()` Promise가 거부되더라도 오류를 처리하고 슬라이드 이동은 계속한다.
- 인쇄 경로에서는 영상을 재생하지 않는다.

## 검증

- 활성 영상은 `play()`되고 비활성 영상은 정지·초기화되는 회귀 테스트를 먼저
  실패하게 만든다.
- 실제 Chrome에서 영상 슬라이드 직접 진입과 슬라이드 이동 후 자동재생 상태를
  확인한다.
- 기존 전체 테스트와 JavaScript 문법 검사를 실행한다.
