# AI 창업 캠프 기술 중심 사업 맥락 보강 설계

## 목표

현재 77장 발표자료를 투자설명회형 자료로 바꾸지 않고, 비행제어 기술 발표를
주축으로 유지하면서 창업지원단이 교육 아이템으로서의 의미를 이해할 수 있게
도입부와 마무리의 사업 맥락을 보강한다.

발표의 중심은 계속 `의의 → 하드웨어 → 소프트웨어 → 시연·실습`이며, 시장 규모,
매출 전망, 투자 요청은 다루지 않는다.

## 선택한 방향

세 가지 선택지 중 기술 중심의 사업적 북엔드 방식을 사용한다.

1. 투자 피치 중심: 사업성은 강하지만 실제 기술 역량과 트러블슈팅이 밀린다.
2. 기술 중심 + 사업적 북엔드: 기술 본편은 유지하고 앞뒤에서 교육 상품의 의미와
   확장 경로만 설명한다.
3. 순수 기술 교안: 기술 깊이는 유지되지만 창업지원단 대상 발표의 이유가 약하다.

사용자 정리에 따라 2번을 선택한다. 사업성은 기술을 대신하는 별도 주제가 아니라,
직접 만든 기술·실패 기록·검증 체계를 반복 가능한 교육 경험으로 묶을 수 있다는
결론으로만 제시한다.

## 슬라이드 변경 범위

- 1번: `기술 교안`보다 발표와 체험의 성격이 드러나도록 부제를 다듬는다.
- 11번: 이 장이 짧은 사업 맥락이고 이후부터 기술이 본론임을 명시한다. 사업성의
  근거는 시장 수치가 아니라 설계·실패·측정·수정 과정의 재현성으로 한정한다.
- 12번: 현재 발표와 실습이 교육 모듈의 시제품이라는 의미를 설명하되, 완성된
  상품이나 매출이 이미 존재하는 것처럼 말하지 않는다.
- 23번: 차기 PCB 주문은 진행 중이고, 납땜 작업과 알리익스프레스 부품 납기가
  일정 위험이라는 현재 실행 상태를 짧게 밝힌다.
- 76번: 안정 호버와 거리·광류 제어 다음의 확장 목표를 `다중 드론 sim-to-real
  경로계획·군집 제어 시스템`으로 구체화한다. 아직 검증하지 않은 목표라는 표시를
  카드 안에 직접 넣는다.
- 77번: 기술을 측정 가능한 형태로 만들고 이를 교육 가능한 형태로 전달한다는
  결론으로 마무리하되 Q&A 화면의 간결함은 유지한다.

나머지 기술 설명, 실측 수치, 영상, 실습, 검증 완료/진행 중/미검증 경계는 바꾸지
않는다. 총 슬라이드는 77장, 영상은 10개, 발표자 노트는 77개를 유지한다.

## 발표 흐름

1. 의의: 드론 제어 문제를 설명하고 직접 만든 이유를 보여준 뒤, 그 과정이 교육
   아이템이 될 수 있는 이유를 2장으로 정리한다.
2. 하드웨어: 기체·보드 제작과 반복 설계, PCB 조달·조립의 현실적인 제약까지
   실행 과정으로 보여준다.
3. 소프트웨어: 자세 추정, SIL, PID, 헤딩, 안전장치, 자동착륙의 문제 해결 과정이
   본론이다.
4. 시연·실습: 실제 호버 영상, 실측 로그, 체험과 검증 현황으로 기술 주장을
   확인한다.
5. 다음 단계: 단일 기체 기반을 먼저 검증한 뒤 다중 드론 sim-to-real로 확장한다.

## 근거와 성숙도 표현

- 현재 PCB 주문 및 일정 위험은 2026-08-10 사용자 제공 발표 준비 정리를 근거로
  하며, `BRIEF.md`에 보존한다.
- 다중 드론 경로계획·군집 제어는 목표일 뿐 구현 완료로 표현하지 않는다.
- 75번의 검증 완료/진행 중/미검증 표와 `SOURCES.md`의 성숙도 경계를 유지한다.
- `검증`, `완료`, `안정`이라는 단어는 기존 저장소 증거가 있을 때만 사용한다.

## 산출물과 검증

- HTML 기준본과 발표자 노트를 수정한다.
- 사용자 제공 방향을 `BRIEF.md`에 기록하고 `SOURCES.md`에서 연결한다.
- 기술 중심 구조, 금지된 투자 피치 문구, PCB 상태, 미검증 다중 드론 목표를
  자동 검사한다.
- PPTX를 다시 생성해 77장, 노트 77개, H.264 영상 10개와 ZIP 무결성을 확인한다.
- 1·11·12·23·76·77번을 PDF 렌더링해 글자 잘림과 기술/사업 비중을 확인한다.

## 열린 파일 보호

PPTX가 OnlyOffice에서 열려 있으면 원본을 덮어쓰지 않는다. 먼저 별도 임시 출력으로
생성·검증하고, 잠금이 사라진 뒤에만 저장소의 정식 PPTX를 교체한다.
