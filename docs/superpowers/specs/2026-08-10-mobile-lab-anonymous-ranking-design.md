# 모바일 드론 랩 익명 식별자·최고점 집계 설계

## 목표

학생이 이름을 입력하지 않아도 서로 구분되는 익명 표시 이름을 제공하고, 같은 표시
이름으로 여러 번 제출한 결과는 순위표에서 최고점 한 건만 보이게 한다.

## 학생 식별자

- 최초 접속 시 Web Crypto로 32비트 난수를 만들고 `익명-XXXXXXXX` 형식의 대문자
  16진수 이름을 생성한다.
- 생성한 익명 이름만 `localStorage`의 버전이 붙은 키에 저장한다. 실명이나 사용자가
  편집한 이름은 저장하지 않는다.
- 같은 브라우저·같은 출처에서는 재접속과 재도전에도 같은 익명 이름을 사용한다.
- 저장소 접근이 차단되면 현재 페이지 수명 동안 같은 이름을 사용하며 체험은 계속된다.
- 입력란은 생성된 익명 이름으로 시작한다. 사용자가 입력란을 비운 경우에도 제출에는
  현재 브라우저의 익명 이름을 사용한다.

## 서버 집계

- 기존 UUID 기반 멱등성과 제출 용량 제한은 유지한다.
- 이름은 기존 검증처럼 제어문자를 거부하고 앞뒤 공백을 제거한 값을 사용한다.
- 비교는 정리된 이름의 대소문자와 유니코드를 포함한 완전 일치 기준이다.
- 이름별로 가장 높은 점수 한 건만 공개 순위에 포함한다. 동점이면 먼저 접수된 기록을
  유지한다.
- `count`는 전체 제출 횟수가 아니라 고유 표시 이름 수를 뜻한다.
- 서버가 참가자를 인증하지 않으므로 같은 이름을 쓴 요청을 실제 동일인이라고 보장하지
  않는다. 이 규칙은 로그인 없는 교육 행사에서 중복 표시를 줄이는 집계 규칙이다.

## 배포·호환성

- 새 식별자 모듈은 정적 release manifest에 명시한다.
- 런타임 CDN이나 계정·쿠키·외부 저장소는 추가하지 않는다.
- 학생 체험은 점수 서버가 없어도 기존처럼 로컬에서 완료된다.

## 검증

- 난수의 리터럴 출력, 저장된 값 재사용, 저장소 실패 대체 동작을 Node 단위 테스트로
  검증한다.
- 실제 Chrome에서 기본 익명 이름과 재시작 후 동일 이름 사용을 검증한다.
- 실제 HTTP 서버에서 동일 이름의 낮은 점수·높은 점수·동점을 제출해 최고점 한 건과
  고유 이름 수를 검증한다.
- 기존 50명 동시 제출, UUID 멱등성, 입력 검증, 모바일 뷰포트 검증을 다시 실행한다.
