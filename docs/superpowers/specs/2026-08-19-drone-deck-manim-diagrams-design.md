# 드론 발표자료 Python 정지 도판 설계

## 목표

84장 HTML 기준본의 설명용 도판 13개를 Python/Manim으로 그린 1280×720 PNG로
구성한다. 분류·비교·상태 전환은 모든 항목을 한 화면에 동시에 놓아, 청중이 영상을
기다리지 않고 차이를 바로 비교할 수 있게 한다.

## 범위

대상은 4·5·6·7·9·10·11·12·46·63·64·71·81번 슬라이드이다.

- 의의·작동원리: 드론 분류, 조종자 증명, 비행체와 UAM, 임무별 요구 사양,
  쿼드콥터의 힘과 운동, 헬리콥터–쿼드콥터 토크, 군집 확장
- 엔지니어링: 자세 복원, SIL 폐루프, RC 두절 Failsafe, 착지 관측 한계,
  공유 상태 경쟁, 모터 출력 균형

기존 센서 원리·제어 원리·실기 시연 영상 14개는 영상으로 유지한다.
`mobile-lab-qr.svg`는 스캔 기능 때문에 SVG로 유지한다. 10분 요약본과 PPTX·PDF는
이번 변경 범위에 포함하지 않는다.

## 시각 언어

- 1280×720 PNG, 남색 배경 `#06152F`, 슬라이드 안에서 `object-fit: contain`
- 본문 `#F7FAFF`, 주 관계 `#48A8FF`·`#5FE3F3`, 정상 `#55D68B`, 주의
  `#FFD166`, 실제 위험·오류만 `#FF6474`
- Noto Sans CJK KR, 주요 글자 26px 이상
- 슬라이드 제목과 중복되는 이미지 내부 제목 금지
- 비교 대상은 같은 좌표계·같은 크기·같은 기준선에 동시 배치
- 긴 문단, 숫자 카드, 장식용 그라디언트, 순차 재생을 전제로 한 문구 금지
- 짧은 설명은 명사형, 완전한 문장은 `~이다`로 통일

## 도판별 구성

1. `DroneClassificationStatic`: 고정익·단일로터·멀티로터·수직이착륙기를 같은
   행에 놓고 멀티로터 안의 쿼드콥터를 강조한다.
2. `QualificationWeightStatic`: 4·3·2종의 최대이륙중량 구간과 1종의
   `최대이륙중량 25kg 초과`·`연료 제외 자체중량 150kg 이하` 조건을 분리해
   동시에 보여준다.
3. `AircraftUamStatic`: 고정익·헬리콥터·멀티콥터·eVTOL의 강점과 교환 조건을
   한눈에 비교하고, eVTOL과 버티포트·운항·교통관리의 연결을 작게 덧붙인다.
4. `MissionSpecsStatic`: 공연·물류·안전감시·국방 정찰의 장면과 요구 사양을
   2×2로 동시에 배치한다. 작전 절차는 다루지 않는다.
5. `QuadcopterForceMotionStatic`: 올바른 X형 기체로 상승·호버링·하강·수평
   이동을 2×2로 비교하고 합추력과 무게의 상대 관계를 같은 규칙으로 표현한다.
6. `HelicopterQuadcopterTorqueStatic`: 2D 평면도에서 헬기의 메인로터 반작용
   토크–꼬리로터 힘과 쿼드콥터의 CW·CCW 반작용 토크를 좌우 비교한다.
7. `SwarmSystemStatic`: 단일 기체와 군집 체계를 나란히 두고 공통 좌표·통신·
   상대 위치·경로/충돌 회피·집단 안전의 추가 요소를 펼친다. 군집은 후속 목표이며
   미구현·미검증임을 고정 표시한다.
8. `AttitudeCorrectionStatic`: 외란→센서 관측→모터 출력 차이→복원 토크의
   폐루프를 한 장에 펼친다.
9. `SilClosedLoopStatic`: 가상 물리→센서 합성→실제 비행 코드→모터 출력→가상
   물리의 전체 고리를 동시에 보인다. host SIL이며 실비행 증거가 아님을 표시한다.
10. `FailsafeTimelineStatic`: RC 두절의 제한 하강 경로와 치명적 고장의 즉시 정지
    분기를 같은 상태도에 보인다. 고정 시간이나 보편 출력값은 넣지 않는다.
11. `LandingObservabilityStatic`: 정지와 등속 하강의 동일한 IMU 관측과 거리 센서가
    제공할 수 있는 추가 단서를 좌우 비교한다. 폐루프 착지는 미검증임을 표시한다.
12. `SharedStateRaceStatic`: 통신 코어와 제어 태스크의 읽기–수정–쓰기가 겹치는
    순서를 두 레인에 동시에 보인다. 가능한 race이며 관측된 사고가 아님을 표시한다.
13. `TelemetryMotorBalanceStatic`: 올바른 X형 모터 배치와 테더 구간의 집계 관계
    `M3 평균 > M1 평균`을 함께 보인다. 원인은 확정하지 않는다.

## 소스 구조

- `static_diagram_visualizations.py`가 13개 정지 장면을 제공한다.
- 기존 `audience_visualizations.py`, `significance_visualizations.py`,
  `engineering_visualizations.py`의 검증된 도형·색상·기술 의미를 재사용한다.
- `render_visualizations.sh`는 기존 9개 Python 영상과 신규 13개 PNG를 각각
  렌더링한다. PNG는 Manim의 마지막 프레임 저장 기능으로 생성한다.
- HTML은 13개 `img[data-python-static]`를 사용하며, 13개의 중간 MP4는 삭제한다.

## 검증 계약

- 13개 정지 장면이 Manim dry-run을 완료해야 한다.
- 13개 PNG는 정확히 1280×720이고 비어 있지 않아야 한다.
- HTML은 정확히 84장, 영상 14개, Python 정지 도판 13개를 가져야 한다.
- 각 대상 슬라이드는 정확한 PNG 하나를 주 시각자료로 사용하고 논리 너비가
  1040px 이상이어야 한다.
- 13개 설명용 MP4와 교체 전 SVG는 참조와 파일이 남아 있지 않아야 한다.
- QR SVG는 정상 로드되어야 한다.
- Chrome 1280×720 전수 렌더에서 글자 잘림, 단어 내부 줄바꿈, 이미지–제목
  겹침이 없어야 한다.
- 법적 기준과 host SIL·벤치·테더·실비행의 증거 경계는 `SOURCES.md`와 일치한다.
- 기존 PPTX·PDF 산출물은 수정하지 않는다.
