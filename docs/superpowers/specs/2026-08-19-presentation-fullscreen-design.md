# 발표자료 전체화면 보기 설계

## 목적

`present.sh`가 연 Chrome 창을 별도 프로그램 없이 바로 발표 화면으로 사용한다.
발표 대본과 발표자 노트는 화면에 표시하지 않는다.

## 동작

- 하단 도구 모음에 `전체화면` 버튼과 `F` 단축키 안내를 둔다.
- 버튼 또는 `F`를 누르면 브라우저 Fullscreen API로 전체화면을 시작하거나 종료한다.
- `Esc`를 누르면 브라우저 기본 동작으로 전체화면을 종료한다.
- 전체화면 중에는 왼쪽 썸네일과 하단 도구 모음을 숨긴다. 마우스를 움직일 때만
  하단 도구 모음을 잠시 표시한다.
- 기존 화살표·PageUp/PageDown·Space 이동과 영상 자동재생·이탈 초기화 동작은
  유지한다.
- Fullscreen API를 사용할 수 없거나 브라우저가 요청을 거부하면 화면 하단에
  Chrome 메뉴의 전체화면 사용을 안내한다.

## 적용 범위

본편과 10분 발표본의 공용 `deck-stage.js` 및 `present.sh`에 같은 동작을 적용한다.
버튼은 기존 검은색 하단 도구 모음에 맞춰 작은 흰색 아이콘과 텍스트로 구성한다.
발표 내용과 시각자료에는 변경을 가하지 않는다.

## 검증

- 실제 Chrome에서 `F` 입력으로 전체화면 진입·종료와 발표 상태 전환을 확인한다.
- 전체화면 진입 시 썸네일·도구 모음이 숨는지 확인한다.
- 런처가 전체화면 조작법을 출력하고 Chrome 종료 뒤 서버와 임시 프로필을
  정리하는지 확인한다.
- 본편과 10분 발표자료의 기존 브라우저·영상·레이아웃 회귀 검사를 실행한다.
