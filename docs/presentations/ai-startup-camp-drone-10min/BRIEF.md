# 자작 드론 비행 제어 개발 결과 발표자료 제작 기준

## 목적

기존 본편에서 자작 드론의 하드웨어, 비행제어 소프트웨어, 검증 과정과
실기 증거를 골라 14장의 결과발표로 구성한다. 기술 결과가 본론이며
사업성과 교육 적용은 도입과 결론의 보조 맥락이다.

## 구성 원칙

- 14장, 16:9 화면
- 기술 내용이 본론이며 사업성과 교육 확장은 도입과 결론에서만 언급
- 한 장마다 주장 하나, 상단 제목과 하단 결론 문장
- 필요성은 개념도, 중반은 실제 CAD·PCB·코드·그래프, 후반은 실기 영상
- 팀 이름, 구체적인 날짜, 커밋 해시, 구체적인 발표·시연 시간 미표기
- 완전한 문장은 `~이다` 계열, 짧은 설명은 명사형
- 실제 비행·벤치·SIL·계획을 서로 구분하고 미검증 결과를 성과처럼 표현하지 않음
- 실제 기체 조종 체험과 중간 퀴즈 미포함

## 결과 장표 계약

- 2장: 상용 비행제어기는 현장 운용, 자작 비행제어기는 학습·검증 목적임을 구분
- 4장: 실제 CAD·출력물·제어 보드, 프린터 점유·직접 작업 계획과 가격 확인 품목별 산정
- 7장: Roll 믹서 보정 R의 부호 오류를 증상에서 SIL 재현과 수정 검증까지 추적
- 9장: 고정된 보편 수치 대신 안쪽 각속도 루프와 바깥 자세 루프의 상대 시간척도
- 11장: 조종 신호, 호버 추정과 스로틀 조건에 따른 전환, host·SIL·보드·실기 증거 경계
- 13장: 단기·중기·장기 목표와 아직 구현하지 않은 단계의 명시
- 14장: 하드웨어·소프트웨어·재현 가능한 검증·기술 학습 결과의 종합

## 제작 규모 산정 계약

- 일정 가정: 부품 보유, 조립 완료 FC PCB, 프린터 한 대, 첫 출력 성공
- 시간 분리: 프린터 점유, 직접 작업 인시, 전체 경과
- 화면 표현: 직접 작업은 시간으로 풀어 쓰고, 전체 경과는 프린터 한 대 기준의 계획값으로 표시
- 가격 범위: 실제 구매 SKU가 아닌 대체품을 포함한 가격 확인 참고 부품
- 가격 구성: 모터·ESC·MCU/센서·프레임·배터리/프로펠러의 1대 기준 항목별 합계
- 제외 범위: FC PCB·전원·배선·체결·배송·세금·인건비·재출력·비행 튜닝
- 해석 경계: 가격이 확인된 참고 품목의 합계이며 완성기 총원가나 확정 BOM이 아님
