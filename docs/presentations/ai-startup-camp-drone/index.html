수식은 알파 값과 토크 계산 두 곳에만 나옵니다. 나머지는 전부 그림과 실측 데이터입니다.
프로펠러는 위로 미는 힘만 만듭니다. 방향을 바꾸는 부품은 없습니다.
  • 네 개를 모두 세게 돌리면 위로 올라갑니다
  • 한쪽 두 개를 더 세게 돌리면 그쪽이 들려 기울어지고, 기울어진 방향으로 미끄러져 갑니다
  • 대각선 두 개를 더 세게 돌리면 회전 반작용이 남아 제자리에서 돕니다
즉 드론 조종은 네 모터의 출력 배분 문제로 환원됩니다. 사람이 직접 배분하는 것은 불가능에 가깝고, 그래서 컴퓨터가 대신합니다.
조금 기울면, 기울어진 쪽으로 힘이 쏠려 더 빠르게 기웁니다. 가만히 두면 넘어지는 것이 정상입니다.
1 · 자전거
가만히 서 있으면 넘어집니다. 사람이 계속 미세하게 조작해서 서 있습니다.
2 · 드론
같은 문제입니다. 다만 사람의 반응 속도로는 늦습니다. 넘어지는 데 1초도 걸리지 않습니다.
3 · 그래서
1초에 1000번, 기울기를 재고 네 모터의 출력을 다시 배분하는 컴퓨터가 필요합니다.
이 컴퓨터를 비행 제어 컴퓨터(Flight Controller, FC)라고 부릅니다. 오늘 이야기의 대부분은 이 FC 안에서 일어납니다.
① 잰다
센서로 기울기와 회전 속도를 읽는다
② 비교한다
지금 자세와 원하는 자세의 차이를 구한다
③ 배분한다
차이를 줄이도록 네 모터 출력을 나눈다
④ 다시 잰다
기체가 움직였으니 ①로 돌아간다
1,000 회
이 고리가 1초에 도는 횟수. 사람의 반응 속도는 여기에 미치지 못합니다.
고리 어디 한 곳이라도 부호가 뒤집히면, 자세를 바로잡는 대신 넘어뜨리는 방향으로 힘이 들어갑니다. 오늘 다룰 문제의 절반이 여기서 나왔습니다.
안이 보이지 않으면 가르칠 수 없다
완제품 제어기는 잘 날지만, 왜 잘 나는지가 상자 안에 있습니다. 교육 재료로는 쓸 수 없습니다.
실패를 재현할 수 있어야 한다
직접 만든 코드라야 일부러 고장 내볼 수 있습니다. 고장을 재현할 수 있으면 안전장치를 검증할 수 있습니다.

기술적 차별점
완제품 조립법에서 끝나지 않고, 부호 반전·바이어스·축 변환 오류를 재현하고 측정으로 고치는 과정을 보여줍니다.
왜 반복 가능한가
비행 없이 컴퓨터 안에서 검증하는 체계를 갖췄습니다. 기체를 부수지 않고 같은 실습을 몇 번이든 돌릴 수 있습니다.
여기서 말하는 사업성은 기술을 대신하는 말이 아닙니다. 기술 개발 과정을 다른 사람이 따라 할 수 있는 실습으로 묶는 것이 교육 아이템의 출발점입니다.

가벼우면서 휘지 않아야 합니다. 둘은 서로 반대 방향의 요구입니다.
  • 암이 휘면 모터의 추력 방향이 바뀌어, 제어기가 계산한 값과 실제 힘이 어긋납니다
  • 속을 비우고 리브를 넣는 트러스 구조로 무게를 줄이면서 굽힘 강성을 확보했습니다
  • 암은 교체형입니다. 추락 시 암 하나만 다시 출력하면 됩니다
3D 프린팅을 전제로 설계했기 때문에, 실패한 형상을 하루 안에 다시 뽑아 비교할 수 있었습니다.
  • 상·하판 분리 — 배터리와 배선을 사이 공간에 넣어 무게 중심을 낮췄습니다
  • 육각 패턴 타공 — 하중 경로를 남기면서 면적을 덜어냈습니다
  • 제어 보드는 상판 위, 모터 배선에서 가장 먼 자리에 둡니다
보드 위치는 나중에 문제가 됩니다. 모터에 흐르는 전류가 자기장을 만들어 방위 센서를 오염시키기 때문입니다. (세션 3에서 다룹니다)
화면에서 괜찮아 보이던 형상이, 손에 쥐면 아닌 경우가 많았습니다.
  • 모터 마운트 나사 간격이 실제 모터와 어긋난 경우
  • 층 방향(적층 방향)과 하중 방향이 어긋나 암이 쪼개진 경우
  • 배선 통로가 없어 조립 후에 선을 넣을 수 없던 경우
설계 → 출력 → 조립 → 폐기의 사이클을 짧게 유지하는 것이, 결과적으로 가장 빠른 길이었습니다.
  • ESP32-S3 한 개에 모터 4채널, IMU 2개(SPI), 지자기센서(I2C)를 모았습니다
  • 12V 입력에서 5V·3.3V를 만들고, 전원 경로에 보호용 MOSFET을 두었습니다
  • GPS·초음파 자리는 배선만 미리 빼두었습니다 (아직 사용하지 않음)
  • 디버깅용 USB와 부트·리셋 스위치를 보드 위에 유지했습니다
회로도의 핀 이름이 그대로 펌웨어의 상수 이름이 됩니다. 두 곳이 어긋나면 증상이 부호 오류처럼 나타나서, 원인을 찾는 데 시간이 오래 걸립니다.

센서를 교체하면 배선을 다시 만들어야 했다 IMU 2개 · 지자기센서를 보드에 직접 실장
교육 관점에서 중요한 것은 측정할 수 있게 만드는 것입니다. 측정점이 없는 보드는 문제가 생겼을 때 추측밖에 할 수 없습니다.
현재 실행 상태 · 차기 PCB는 주문 진행 중입니다. 납땜 작업과 알리 부품 납기는 일정 위험으로 관리하고 있습니다.

모터 믹서 — 네 모터에 출력을 나누는 식
M1 = T − P + R − Y
M2 = T + P − R − Y
M3 = T − P − R + Y
M4 = T + P + R + Y
T는 전체 출력, R·P·Y는 좌우기울기·앞뒤기울기·회전 보정량입니다. 출력이 허용 범위를 넘으면 세 보정량을 같은 비율로 줄여 토크 비율을 보존합니다.
부호가 하나라도 틀리면 기체는 자세를 바로잡는 대신 넘어지는 쪽으로 힘을 줍니다. 그래서 벤치에서 한 모터씩 돌려 물리적으로 확인합니다.
모터가 도는 실험에서는, 규칙이 코드보다 먼저입니다.
  1. 벤치 테스트에서는 프로펠러를 제거한다
  2. 전원을 넣기 전에 극성·핀 배치·모터 순서·보정 방향을 확인한다
  3. 배터리 대신 전류 제한을 걸 수 있는 파워서플라이로 시작한다
  4. 한 번에 한 모터만, 저속 상한(1250µs)을 걸고 돌린다
  5. 조종 신호는 USB 연결로 보낸다 (무선 패드는 WiFi와 간섭)

급기동 중 — 자이로에 맡긴다
가속·감속·외부 충격이 섞인 상태입니다. α를 0.9998까지 올려 가속도계 비중을 거의 0으로 줄입니다.
고정된 가중치를 쓰지 않고, 매 순간 가속도 크기를 보고 가중치를 다시 정하는 방식입니다. 이것이 적응형(adaptive) 상보필터입니다.
α ≈ τ / (τ + dt)
dt = 0.001초 (1초에 1000번 계산)
  1. τ = 0.5초로 만들고 싶다. α는?
  2. τ = 5초로 만들고 싶다. α는?
  3. 계산 주기가 1kHz에서 500Hz로 느려지면(dt=0.002), 같은 τ를 유지하려면 α는 커져야 할까 작아져야 할까?
이 실습에서 확인할 것
  • α는 대부분 0.99 이상입니다. 소수점 셋째 자리 이하의 차이가 성격을 바꿉니다
  • 그래서 α를 직접 손으로 고치는 것은 위험합니다. τ를 정하고 코드가 α를 계산하게 만드는 편이 안전합니다
  • 계산 주기가 바뀌면 같은 α가 다른 의미를 갖습니다
실제로 이 프로젝트에서도 α를 직접 적지 않고, 원하는 시간상수에서 역산한 값을 상수로 두었습니다.
